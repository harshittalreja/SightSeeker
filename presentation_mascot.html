Core Breakthrough

Most mobile robots need a pre-built map and hard-coded waypoints. SightSeeker uses YOLO26 object detection + language grounding: the operator just says "find the red barrel", and the robot explores, recognises the object and drives to it while avoiding obstacles.

💥 The Static Floorplan Trap

Industrial robots crash when pallets or humans shift into their blind spots. SightSeeker replaces brittle coordinates with real-time visual perception.

Proposed Solution

SightSeeker: Perception & Decision Engine

Four tightly coupled layers delivering autonomous physical intelligence.

🗣️

Natural Language

Language grounding maps goals like "find my phone" to detector classes (synonyms, colours, typo-tolerant). Built so a VLM such as CLIP can slot in later.

👁️

YOLO26 Vision

YOLO26, Ultralytics' newest detector, finds 80 COCO object classes in real time with boxes and confidence scores: the large model on an NVIDIA GPU, the nano model on a plain CPU.

🧭

Free-Space Planner

A Vector Field Histogram (VFH) planner picks the open direction closest to the goal from a 360° LiDAR scan; a separate safety layer always leaves room to stop.

🌐

120 m 3D Simulation

Validated in a 120 m WebGL warehouse with a robot camera, LiDAR and its own map: 1,000 random trials, 100% success, 0 collisions.
